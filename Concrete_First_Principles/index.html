Concrete First Principles

This platform was developed by Dr. X.Y. Lu with the assistance of ChatGLM. It models concrete from first principles — drawing on cement chemistry, particle packing, suspension rheology, fracture mechanics, and corrosion electrochemistry — through eight axioms, twenty-two governing equations with parameter tables and a provenance ledger, and a working simulator that chains mix design, fresh-state properties, mechanics, fibers, and four durability arenas into twenty computed figures. It is intended not only as a working memo, but as an open invitation: those who find it promising are warmly welcome to enrich and extend it (see How to Contribute).

Concrete Design & Multi-Physics Simulator

Chain: mix → grading (M19) → rheology (M15+M17) → admixtures (M9/M10) → multi-blend SCM (M16) → mineralogy/gypsum (M18) → strength + fibers (M14/M17) → fracture (M7) → durability: frost (M10), corrosion (M20), ASR/AAR (M21), sulfate (M22). Inputs are constrained to the physical ranges listed under Input Specifications; out-of-range clamps are reported above the results.

Curve Gallery

All 20 figures render for every preset; conditional series within a figure (e.g. the fiber rupture cap) appear only when physically active. Every figure prints its own error with the culprit named.

Generate PDF Report

A · vector text, landscape A4 — charts re-render at print size (one per row, full column width) on beforeprint. B · per-panel raster + jsPDF — equations re-render in light theme; page cuts fall only at block boundaries, so charts are never split; only oversized text blocks slice. (A former server option was removed: static hosting has no /api/pdf.)
